# DHAROHAR (Dad's Edition) — iPhone (iOS) Install Guide

1. Create a free Public GitHub repo (e.g., `dharohar-ios`) and upload all files from this folder (`index.html`, `manifest.json`, `sw.js`, and `icons/`).
2. Go to **Settings -> Pages -> Branch: main / (root)** -> click **Save**.
3. Open the GitHub Pages link in **Safari** on the iPhone.
4. Tap **Share (↑) -> Add to Home Screen -> Add**.

DHAROHAR will appear on the Home Screen with your maroon & gold logo, open full-screen, work 100% offline, and never expire!
